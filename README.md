# Teamwork timer for Sill

Track time on Teamwork tasks from [Sill](https://github.com/proliminal/sill). Start a timer for a task number, or for a project
when the time isn't on a task. Stop it from the popup or Sill's quick menu, and log the time. Pin the popup to keep the
timer on screen.

## Install

1. Download the latest release.
2. Unzip it into `%APPDATA%\Proliminal\Sill\plugins\TeamworkTimer`.
3. Restart Sill and allow the plugin when it asks.
4. In Sill's settings, open **Teamwork timer** and enter your Teamwork site and API token.

Needs Sill with SDK 2.1 or newer. Your token is stored encrypted on your PC; only task numbers, descriptions, times and tags
are sent, to your own Teamwork site.
