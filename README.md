# Teamwork timer for Sill

Track time on Teamwork tasks from [Sill](https://github.com/proliminal/sill). Start a timer for a task number, stop it
from the popup or Sill's quick menu, and log the time on the task. Pin the popup to keep the timer on screen.

## Install

1. Download the latest release.
2. Unzip it into `%APPDATA%\Proliminal\Sill\plugins\TeamworkTimer`.
3. Restart Sill and allow the plugin when it asks.
4. In Sill's settings, open **Teamwork timer** and enter your Teamwork site and API token.

Needs Sill with SDK 1.3 or newer. Your token is stored encrypted on your PC; only task numbers, descriptions and times
are sent, to your own Teamwork site.
